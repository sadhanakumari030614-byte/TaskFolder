# TaskFlow

TaskFlow is a task management web application for creating and managing tasks.

## Features

- Add new tasks
- Edit tasks
- Save changes
- Delete tasks
- Set task priority
- Set due date
- Filter tasks by priority
- FastAPI backend
- SQLite database
- REST API
